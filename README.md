# Python: Meu Caderno de Estudos

Bem-vindo ao meu repositório de estudos de Python.

Aqui eu reúno **tudo o que aprendo sobre Python**: da sintaxe básica até ferramentas, bibliotecas e projetos práticos. A ideia é que este repositório cresça junto comigo, funcionando como caderno de anotações, banco de exercícios e portfólio.

> **Em construção constante.** Toda vez que eu estudar algo novo, vai aparecer por aqui.

---

## Objetivo

Construir uma base sólida em Python e documentar a jornada, cobrindo:

- Fundamentos da linguagem
- Ferramentas do ecossistema
- Bibliotecas de dados e matemática
- Projetos práticos
- Anotações e exercícios
